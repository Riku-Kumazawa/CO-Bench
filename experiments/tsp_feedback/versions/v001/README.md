# TSP：固定した初期解に対するフィードバック比較

既存Qwen初期解（dev = 0.8852062501473457）を共通の親として、support・neutral・switchから各9候補を独立に生成する。
新規生成は27回。反復seedは101〜109で、同じ反復の3条件には同じseedを割り当てる。
各候補の評価結果を別の候補の生成には渡さない。

初期解は元のQwen単発生成のものを使用し、この新実験の条件別結果を見て選び直さない。
主指標は初期devスコアからの差、初期解を上回る割合、候補・ケースの失敗率とする。
失敗は0点として集計し、最高値は補助指標とする。
TSPは分割がないため、元の272入力をdevとして評価する。
この実験だけでは別の問題・初期解への一般化や、連続改善の効果は判断しない。
